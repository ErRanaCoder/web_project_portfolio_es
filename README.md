# Portafolio

Portafolio personal de Erick Gabriel Hernández Rebolledo. Presenta su perfil
profesional, habilidades, herramientas, proyectos destacados y medios de
contacto.

## Funcionalidad

La página adapta su distribución a pantallas de escritorio, tablet y móvil. El
perfil, la lista de habilidades y las tarjetas de proyectos cambian de formato
según el ancho disponible para mantener el contenido legible y sin desplazamiento
horizontal.

## Tecnologías y técnicas

- HTML5 semántico.
- CSS con metodología BEM.
- Flexbox y CSS Grid.
- Media queries para diseño responsivo.
- Fuentes locales con `@font-face`.
- Gradientes, `aspect-ratio` y `object-fit`.
